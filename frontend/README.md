# CFI Dashboard

邀请制共享团队工作台，使用 Vue 3、Vue Router、Vite。需要 Node 24 和 npm；在 VS Code 中打开正式项目目录，终端进入 `frontend/`。

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

开发代理将 `/api` 发往本机 `http://127.0.0.1:8002`。在终端显示的地址打开页面，输入项目所有者发放的读取令牌。读取令牌使用当前标签页的 `sessionStorage` 保存，刷新恢复；点击“断开”或读取接口401会清除。共享读取令牌可以查看全部已接入仓库；付费触发凭据另行输入，仅临时保存在内存。

```powershell
npm test
npm run build
```

构建输出为 `dist/`。生产环境由 HTTPS 反向代理提供静态文件，将 `/api` 转发后端，其余页面路由回退到 `index.html`；`vite preview` 仅用于本地检查构建结果。任何令牌都不应写入源码、构建变量或 URL。

当前已有最近20条事件列表、失败明细、相似历史、已有诊断读取和独立触发入口。历史显示来源事件、Job、检索相似分数及错误文本；诊断中的历史引用可跳转来源并展开对应证据。检索降级、未启用、未就绪与正常无匹配分别展示，诊断轮询不会反复检索历史。完整分页、仓库筛选和个人登录仍未提供。真实模型调用由授权者明确确认后发起；自动化测试使用假响应，不产生模型费用。
